## Dataset

The dataset used in this exercise is the publicly available paediatric chest X-ray dataset:

- Mooney, P. (2018) *Chest X-Ray Images (Pneumonia)*. Kaggle. <https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia>

The dataset is not in this repository; download from Kaggle.

## What is not part of this repo

- Trained model weights (`.keras` / `.h5`) - generated by the notebook on each run.
- Chest X-ray dataset - Kaggle is the source.
- Notebook caches (`__pycache__/`, `.ipynb_checkpoints/`).

## Reproducibility notes

- Submitted notebook keeps cell outputs (figures, metrics, results).
- GPU non-determinism: a few F1 points drift between runs.
- Keras `trainable` flag verified explicitly during fine-tuning.
