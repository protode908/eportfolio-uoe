Aims

"In this module we shall:"

  • "Learn about the key paradigms and algorithms in machine learning."
  • "Get an understanding of data analytics based on machine learning and using modern programming tools, such as Python or R."
  • "Experience how machine learning and data analytics can be used in real-world applications."
  • "Acquire the ability to gather and synthesise information from multiple sources to aid in the systematic analysis of complex problems using machine learning tools and algorithms."

(University of Essex Online, n.d.)

Learning outcomes

"On completion of this module, students will be able to:"

LO1 "Articulate the legal, social, ethical, and professional issues faced by machine learning professionals."
LO2 "Understand the applicability and challenges associated with different datasets for the use of machine learning algorithms."
LO3 "Apply and critically appraise machine learning techniques to real-world problems, particularly where technical risk and uncertainty is involved."
LO4 "Systematically develop and implement the skills required to be effective member of a development team in a virtual professional environment, adopting real-life perspectives on team roles and organisation."

(University of Essex Online, n.d.)
