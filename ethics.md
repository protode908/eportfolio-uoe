## Personal data

- Peer names and email addresses are redacted from all published evidence. My own name and email remain visible because this is my e-portfolio.
- No claim in this e-portfolio depends on identifying any individual peer.
- If anything here accidentally identifies a peer, please [open a GitHub issue](https://github.com/protode908/eportfolio-uoe/issues) and I will fix it.

## Copyright

- Third-party images used in the Unit 10 CNN walkthrough are reproduced as inputs for analysis, with attribution shown on the card where they appear.
- If a copyright owner wants attribution corrected or an image removed, please [open a GitHub issue](https://github.com/protode908/eportfolio-uoe/issues).
